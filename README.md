# SALUZ

Protótipo inicial da experiência digital da SALUZ.

## Direção aprovada

A experiência foi construída a partir do sistema:

**Descoberta → Desejo → Exploração → Identificação → Confiança → Compra → Experiência → Recompra**

A SALUZ não deve ser tratada como um catálogo genérico. A proposta deste protótipo é combinar:

- produto;
- momento de uso;
- presenteabilidade;
- curadoria;
- detalhes de marca;
- conversão.

## Estado atual

Esta versão é uma **base visual e funcional**, não o e-commerce final.

Ainda não foram inventados:
- produtos;
- preços;
- estoque;
- frete;
- políticas;
- WhatsApp;
- dados de contato.

Esses elementos devem ser conectados apenas após a definição comercial real.

## Estrutura atual

- Home conceitual responsiva;
- navegação por universos;
- navegação por momento/intenção;
- sistema "Detalhes SALUZ";
- experiência de presentes;
- menu mobile;
- busca conceitual;
- formulário demonstrativo;
- componentes preparados para evolução.

## Stack atual

HTML + CSS + JavaScript puro.

Escolha proposital para permitir validar a direção visual sem acoplar o projeto prematuramente a uma plataforma de e-commerce.

## Próxima etapa

1. validar o protótipo visual;
2. definir catálogo inicial;
3. definir operação (estoque, pagamento, frete, logística);
4. decidir Nuvemshop x Shopify;
5. adaptar os componentes para a plataforma escolhida;
6. criar páginas reais de categoria e produto;
7. conectar tracking e conversões.
